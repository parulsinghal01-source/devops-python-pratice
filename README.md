# DevOps Python Practice

This repository contains beginner-friendly Python scripts for DevOps automation practice.

## Purpose

The goal of this repo is to practice Python scripting, Git, GitHub, branches, commits, and pull requests.

## Scripts Included

| Script | Description |
|--------|-------------|
| `disk_check.py` | Checks disk usage and alerts if usage is above 80%. |
| `service_check.py` | Checks whether a service/process is running. |
| `log_error_counter.py` | Counts lines in a log file that contain a specific error message. |

## How to Run

Clone the repository:

```bash
git clone https://github.com/parulsinghal01-source/devops-python-pratice.git
cd devops-python-pratice

## Run a script:

python3 disk_check.py
